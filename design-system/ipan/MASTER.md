# iPan 云盘界面规范

适用于文件工作台、分享、设置、登录、初始化、云盘绑定、公开分享和所有弹层。整体方向参考 Dropbox 桌面 Web 应用：明亮、克制、以文件操作为中心。

## 基础原则

- 白色侧栏与浅灰内容底色建立清晰的工作区层级。
- 主色固定为 `#0061FF`，只用于主操作、选中态、链接和进度。
- 面板保持平面，优先使用 1px 边框和轻量悬停，不使用玻璃、重阴影或大装饰图形。
- 信息层级依靠字号、字重、留白和颜色，而不是编号、标签墙或装饰图表。
- 首要目标是扫描效率和可操作性，视觉表现保持低干扰。

## 色彩

| 用途 | 浅色 | 深色（可选） | 变量 |
| --- | --- | --- | --- |
| 页面底色 | `#F7F8FA` | `#0F141C` | `--op-bg` |
| 面板/侧栏 | `#FFFFFF` | `#161D27` | `--op-surface` |
| 轻表面 | `#F3F4F6` | `#1D2632` | `--op-surface-muted` |
| 主文字 | `#111827` | `#F2F4F7` | `--op-ink` |
| 次文字 | `#6B7280` | `#98A2B3` | `--op-ink-soft` |
| 弱化文字 | `#667085` | `#98A2B3` | `--op-ink-faint` |
| 边框 | `#E5E7EB` | `#263140` | `--op-rule` |
| Dropbox 蓝 | `#0061FF` | `#4D8DFF` | `--db-blue` |
| 蓝色轻底 | `#E8F0FF` | `#172A4F` | `--db-blue-soft` |

- 成功、警告、危险色只用于对应语义，不承担品牌表达。
- 文件夹图标统一使用 Dropbox 蓝，普通文件图标使用蓝色描边与浅蓝填充。

## 字体

- 全站使用现代无衬线：`Inter / Segoe UI Variable / PingFang SC / Microsoft YaHei / Noto Sans SC`。
- 页面标题 28–36px、600–700 字重；卡片标题 18–22px；正文 13–15px。
- 元数据使用 11–13px，必须保持可读对比度，不用极小灰字营造精致。
- 数字和表头启用等宽数字，不单独使用衬线展示字体。

## 布局

- 桌面侧栏宽度 240px：品牌、工作区导航、存储空间、链接解析、账号入口。
- 内容区最大宽度 1360px，页面留白 20–44px；文件表格与卡片使用 12px 圆角。
- 移动端顶部 62px 品牌栏，底部固定三项导航，内容底部预留导航和安全区高度。
- 文件页：标题 + 文件数量/排序说明 + 新建文件夹/上传，下面为搜索、路径和视图切换。
- 设置页：白色导航卡 + 右侧账号/安全/显示设置卡。
- 分享页：来源标签 + 扁平记录列表。

## 文件列表

- 行高 54px，表头 38px，表头浅灰底。
- 列：勾选、名称、大小、修改时间、更多操作。移动端隐藏大小与时间，名称下显示摘要。
- 行悬停使用 `#F9FAFB`，选中使用 `#E8F0FF`，不使用重阴影和左侧粗线。
- 文件图标放在 36px 白色圆角方框中，文件夹为蓝色实心，文件为蓝色描边。

## 文件网格

- 使用自适应网格，卡片间距 12px，白色卡片、1px 边框、10px 圆角。
- 预览区使用浅灰或蓝色轻底，文件夹突出蓝色图标，普通文件显示类型图标和小号类型字标。
- 悬停只改变边框和轻微背景，不上浮、不使用重阴影。

## 控件

- 主按钮：蓝底白字，40px 高，8px 圆角，悬停 `#0052D9`。
- 次按钮：白底、1px 灰边框、深色文字，悬停变蓝。
- 输入框：白底、8px 圆角、灰色边框，聚焦蓝色描边与 3px 轻光环。
- 导航选中态：`#E8F0FF` 背景与蓝色文字/图标。
- 弹窗：白底、12px 圆角、1px 边框、轻阴影；标题 18–20px。
- 图标统一 1.55px 描边和圆端点，纯图标按钮必须提供可访问名称。

## 动效

- 页面进入使用 180–300ms 的 6px 上移淡入。
- 按钮、导航和文件行只过渡背景、边框、颜色，时长 120–160ms。
- 不使用弹跳、漂浮、持续装饰动画；尊重 `prefers-reduced-motion`。

## 可读性与响应式

- 1440×900 与 390×844 为主验证视口。
- 正文和辅助文字保持足够对比度；空输入框、占位文字、表头和弱化元数据都要可读。
- 检查 200% 缩放、长文件名、空目录、错误状态和移动端安全区。

## 实现

- 设计变量集中在 `web/src/global.css` 的 `--db-*` 与 `--op-*`，并保留 `--gh-*` 兼容别名。
- 页面标题统一使用 `.page-header` / `.eyebrow` / `.display`。
- 按钮统一使用 `.btn`、`.btn-primary`、`.icon-control`。
- `.glass-panel` 仅作为历史类名保留为平面表面，不再使用模糊或透明材质。
